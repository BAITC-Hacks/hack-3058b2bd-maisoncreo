# Архитектура

Центральный принцип: **Python decides who qualifies. AI helps explain why.**

```text
User request
    ↓
validation
    ↓
deterministic hard filtering
    ↓
deterministic ranking
    ↓
top <= 3
    ↓
evidence selection
    ↓
evidence validation
    ↓
deterministic final explanation
    ↓
Streamlit UI

OpenAI unavailable/rejected
    ↓
deterministic grounded fallback
```

## Компоненты

- `recommendation_core.py` отвечает за валидацию запроса, допустимость
  кандидатов, жёсткое исключение занятых на выбранную дату подрядчиков и
  детерминированный порядок результатов. Он возвращает не более трёх карточек.
- `explanation_layer.py` работает только с уже выбранными карточками и не может
  менять их состав или порядок. OpenAI при наличии ключа выбирает проверяемые
  основания; Python валидирует их и детерминированно формирует итоговый текст.
- `app.py` загружает данные, предоставляет Streamlit-интерфейс и отображает
  результаты, сообщения о статусе и происхождении данных.
- `data/contractors.csv` — официальный анонимизированный набор из 66 профилей.

OpenAI необязателен. Если `OPENAI_API_KEY` отсутствует, запрос к провайдеру
завершается ошибкой или ответ не проходит проверку, используется
детерминированное обоснованное объяснение. Основной подбор продолжает работать
без API-ключа.

Приложение выдаёт рекомендации и не выполняет бронирование.
