# Демо для жюри

Все три сценария доступны кнопками в интерфейсе и проходят через обычный
конвейер приложения. Результаты пресетов не зашиты в UI.

## 1. «Много вариантов»

`Алматы / 2026-09-30 / корпоратив / Ведущий / 1,000,000 KZT / 6h / русский`

Сценарий показывает несколько подходящих кандидатов, детерминированное
ранжирование и ограничение выдачи максимум тремя карточками.

## 2. «Мало вариантов»

`Алматы / 2026-09-24 / свадьба / Ведущий церемонии / 300,000 KZT / 3h / русский`

Всем жёстким условиям соответствуют ровно два подрядчика. Система возвращает
обоих и не дополняет список неподходящим третьим кандидатом.

## 3. «Нет подходящих»

`Астана / 2026-09-28 / свадьба / Фотограф / 1,000,000 KZT / 8h / русский`

Подрядчики нужной категории в каталоге есть, но никто не проходит все жёсткие
условия, включая доступность. Система показывает понятный результат без
ослабления ограничений.

## Демо за 3 минуты

1. **0:00–0:30** — открыть приложение и кратко показать входные поля: город,
   дату, формат, категорию, бюджет, длительность и язык.
2. **0:30–1:20** — нажать «Много вариантов»: обратить внимание на максимум три
   карточки, стартовую цену, проверенные факты и объяснение.
3. **1:20–2:05** — нажать «Мало вариантов»: показать две карточки и сообщение о
   том, что возвращены все доступные подходящие подрядчики.
4. **2:05–2:40** — нажать «Нет подходящих»: показать ясное сообщение вместо
   пустого экрана или ослабления фильтров.
5. **2:40–3:00** — подчеркнуть, что подбор и порядок детерминированы, занятые
   подрядчики исключаются, а OpenAI влияет только на выбор основания для
   объяснения и не нужен для работы приложения.
